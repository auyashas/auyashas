## 🚀 Featured Projects

### [Portfolio Pro](https://github.com/auyashas/Portfolio-Pro)
A freelancing platform that connects clients with freelancers. Freelancers submit profiles and resumes for admin approval, while clients can explore approved profiles and send job requests.

**Tech:** React, Node.js, Express.js, MySQL

### [Fake Job Posting Analyzer](https://github.com/auyashas/fake-job-posting-analyzer)
A machine-learning application that analyzes job-posting details and predicts whether a listing may be fraudulent.

**Tech:** Python, Streamlit, pandas, joblib, trained machine-learning model

### [Notepad — Notes & Tasks](https://github.com/auyashas/notepad)
An offline Android notes and task-management app with reminders, tags, favourites, search, and local storage. This repository is a fork of [Karthik-Billava/notepad](https://github.com/Karthik-Billava/notepad).

**Tech:** Java, XML layouts, SQLite, RecyclerView, Android Alarm and Notification APIs

### [The Malabar Table](https://github.com/auyashas/restaurant-application)
A restaurant reservation website built as a web technology project, with customer-facing pages and reservation workflows.

**Tech:** PHP, MySQL, HTML, CSS, JavaScript

### [College Canteen Management System](https://github.com/auyashas/college-canteen-management-system)
A desktop-based canteen system with staff authentication, inventory tracking, billing, and database integration.

**Tech:** Java Swing, JDBC, MySQL

### [ShopSmart — E-Commerce Product Catalog](https://github.com/auyashas/ecommerce-nosql-project)
A full-stack product catalog featuring a smart cart, trending products, recently viewed items, reviews, and analytics.

**Tech:** Python, Flask, MongoDB, Redis, HTML, CSS, JavaScript

### [Banking System](https://github.com/auyashas/Banking-System)
